
# 🌸 Tic Tac Toe - CS50 Final Project

#### Video Demo: https://YOUR_VIDEO_LINK_HERE

## Description

This project is a Tic Tac Toe game developed using HTML, CSS, and JavaScript as my CS50 final project.

The game allows a human player (🌸) to play against an AI opponent (🌙). The AI makes decisions automatically after each player move. The goal of the game is to get three symbols in a row horizontally, vertically, or diagonally.

The project includes a score system that tracks the number of wins for both the player and the AI. It also detects wins and draws and resets the game when needed.

### Files in this project:

- **index.html**: Contains the structure of the game board, buttons, and score display.
- **style.css**: Provides the visual design, layout, and background styling of the game.
- **script.js**: Contains the full game logic, including player interaction, AI behavior, win detection, and score system.

### Design Choices

I chose a simple but colorful design with emoji-based characters (🌸 and 🌙) to make the game more fun and user-friendly. The AI is designed with a smart logic approach: it tries to win when possible, blocks the player when necessary, and prioritizes the center and corners.

### Conclusion

This project helped me understand JavaScript logic, DOM manipulation, and basic artificial intelligence concepts in games.
